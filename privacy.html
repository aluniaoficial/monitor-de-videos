2. Dados tratados nesta versão

O aplicativo atual guarda localmente no computador as pastas escolhidas, informações de arquivos de vídeo, itens da agenda e registros manuais de publicações e métricas. Esses dados são usados para organizar a biblioteca e exibir o histórico local. O aplicativo não envia esses dados a um servidor do Monitor de Vídeos nesta versão.

3. Integrações futuras

Quando as integrações oficiais forem implementadas e autorizadas, o aplicativo poderá tratar identificadores de conta, tokens de autorização, metadados de publicação e métricas disponibilizadas pelas APIs para executar as funções solicitadas pelo usuário. Os vídeos selecionados serão enviados à plataforma correspondente para publicação. Os detalhes de armazenamento e retenção desses dados serão atualizados antes de habilitar essas funções.

4. Compartilhamento

Nesta versão, os dados locais permanecem no computador do usuário. Uma integração futura transmitirá apenas os dados necessários à plataforma social escolhida pelo usuário, conforme as permissões autorizadas e as políticas dessa plataforma. Não vendemos dados pessoais.

5. Retenção e segurança

Os registros desta versão permanecem no computador até serem removidos pelo usuário ou até que os dados do aplicativo sejam apagados. O usuário deve proteger o acesso ao computador e manter cópias de segurança dos arquivos originais. As medidas de proteção e prazos aplicáveis às integrações futuras serão descritos antes do lançamento dessas funções.

7. Alterações nesta política

Esta política poderá ser atualizada quando novas funções ou integrações forem habilitadas. A data de atualização será alterada no início desta página.
